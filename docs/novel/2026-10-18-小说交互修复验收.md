# 小说搜索、书架与手动同步验收

范围：`feature/novel-reader`，基线 `502d05e`。官方 `main`、`upstream/main` 和播放器实现未修改。

## 行为变更

- 搜索结果和书架采用响应式封面网格，标题在封面下方；小说搜索先进入详情，再选择书源阅读。聚合只影响展示，不自动合并已有阅读档案。
- 小说与番剧共用历史存储、去重及十条上限，点击历史使用当前搜索类型，无痕模式不写入历史。
- 标题处理支持小说版标记、成对波浪线副标题及括号内完整别名。真实 Bangumi 别名可关联“辉夜姬想让人告白”和“辉夜大小姐想让我告白”；“辉夜魔王式”等无关作品不匹配。
- 书架菜单支持删除确认和取消。删除入架记录保留阅读位置、书签及书源，删除记录可以手动同步，重新加入可以续读。
- 小说只在本地持续保存。移除启动、定时、编辑后、前后台切换及退出阅读的云同步；保留书架“同步小说”和设置“立即同步小说”。启用开关不发起同步。

## 轻小说文库根因及实测

1. 登录后的原始搜索 HTML 使用 `title` 保存完整书名，旧规则读取 `tiptitle` 导致空值异常。按真实返回格式修正规则，不增加猜测字段路径。
2. 旧登录验证会搜索“魔女”，随后用户搜索触发站点“两次搜索间隔不得少于 5 秒”的错误页；旧解析把错误页当成无结果。改为首页退出链接验证登录，并用明确的错误页 XPath 显示站点提示。
3. 真实账号验证：登录后立即搜索“辉夜”返回至少五本，含 `/book/2550.htm` 对应小说；目录与章节读取通过。凭据从进程环境临时传入，测试结束删除临时会话，不写入仓库、配置或日志。
4. 默认规则升级包含 0.1.2 原文摘要，仅替换已知旧默认规则，保留自定义规则和用户删除的书源。

## 复验入口

- `flutter test --concurrency=4 --timeout=30s`
- `flutter test test/live/book_services_test.dart --dart-define=BOOK_LIVE=true`
- `test/live/wenku8_authenticated_test.dart`：仅在进程环境提供 `BOOK_WENKU_USER` / `BOOK_WENKU_PASSWORD` 时运行，禁止在脚本或仓库写入实际值。
- `flutter test integration_test/windows_book_operations_test.dart -d windows`：先启动 `tool/android_ui/fixture_server.py`，使用已有自有视频素材。
- 覆盖率使用完整项目 `flutter test --coverage --branch-coverage`，普通回归与分支采集分开。分批结果合并后对 Git 基线提取增量，不用全库分母稀释新增代码的缺口。
