# Kazumi's book 使用与维护

本软件保留 Kazumi 的番剧功能，并增加轻小说书架、阅读器、跨源续读与 WebDAV 阅读数据同步。产品代码在 `feature/novel-reader`，`main` 保持上游镜像。

## 获取安装包

优先从[本仓库 Releases](https://github.com/ZGCC3890/Kazumi-s-book/releases)下载 Android APK 或 Windows ZIP。也可以打开[本仓库构建记录](https://github.com/ZGCC3890/Kazumi-s-book/actions/workflows/book-ci.yml)，选择产品分支最近一次成功构建，在 Artifacts 下载：

- `Kazumis-book-Android-development`：解压后安装 arm64 APK，适合 Android 手机和平板。应用标识是 `com.zgcc.kazumisbook`。
- `Kazumis-book-Windows-development`：解压 Artifacts 后再解压其中的程序 ZIP，保持目录完整，运行 `kazumis_book.exe`。

两者显示名称都是 **Kazumi's book**。Android 使用独立包名；Windows 使用独立产品名、数据目录和互斥量。0.1.0 起使用本应用自己的固定 Android 签名，以后沿用它覆盖升级。之前的 debug 开发包签名不同，需要先卸载旧开发包。长期签名私钥不进入仓库，通过仓库 Secret `BOOK_ANDROID_SIGNING` 提供。

## 搜索与开始阅读

1. 在“追番”页打开右上角的小说书架，点击“添加小说”；也可直接点击番剧的阅读按钮。
2. 默认小说规则自动获取，不需要手动导入。紧凑选源弹窗同时搜索各源，分别显示结果或具体错误；点击一本书直接阅读。番剧自动搜索会去掉第二季、第二部分、Part 2 等末尾续作标记。高级用户仍可在“小说规则”管理自定义 JSON/URL/文件与索引。
3. “书架”是主导航中紧接“追番”的同级栏目，手机底栏与平板／桌面侧栏都有入口。已入架小说显示当前书源提供的封面，可设为默认启动页。点击书架“添加小说”独立搜索；或在番剧详情点击阅读、在追番卡片点击阅读图标。试读不自动加入书架；读过两个不同章节后退出会询问。接受后关联番剧加入追番并标为“在看”，独立小说只加入书架；旧版已有书架记录保留。
4. 在书架菜单中选择“更换同版本书源”以切换同一文本版本；不同语言、译本或 Web/文库版本应建立其他版本，分别保存进度。

默认提供 LightNovel 中文译文、轻之文库中文原创、文库8、小説家になろう四套规则。前两个源的公开章节支持匿名搜索和阅读；LightNovel 部分章节需站点权限，应用会明确显示限制，不把摘要或隐藏快照当作全文。两个站点分别来自 www.lightnovel.fun 与 www.linovel.net。

文库8站内搜索需要每台设备首次登录本人账号，应用在该源结果旁显示“首次登录”按钮，不打断其他源。会话按书源保存在本地，重启可继续使用；密码不保存，不参与 WebDAV 同步。会话过期或站点主动撤销时需要重新登录。有公开书籍地址时，也可在该源菜单选择“打开书籍链接”，粘贴例如 `https://www.wenku8.net/book/4343.htm` 的详情页链接直接读取，不需要搜索登录。

仓库内规则保存在 [`novel_rules/`](../../novel_rules/README.md)，与应用代码分开导入、更新和删除。规则变更不要求重新安装应用。自定义索引 URL 保存在本机；修改规则后对应目录、正文缓存按规则内容重新计算。连载更新时，在阅读页点击“刷新目录与正文”，重新取得目录和当前章内容并恢复阅读锚点；刷新失败会显示错误，点击重试会再次联网刷新。

规则请求站点公开页面/API或本人本机会话，不内置共享账号。文库8此前的 Dart 403 经单变量实验证明与 Chrome UA、gzip 请求有关；规则改用应用 UA 与 identity 后，Dart 已取得 23 章、93 段正文、13 张有序插图及首张 JPEG。生产 Dio 会话链路另有实测记录。小説家になろう API 在本环境仍有 403，未宣称其正文联网验收完成。站点访问验证、429 限流等 HTTP 错误会直接显示；不会自动换代理或替换成其他来源。

## 阅读与跨源续读

支持滚动/左右翻页、目录、章内进度和章节拖动、字体字号、行距、页边距、四种阅读主题、阅读遮罩亮度、横竖屏及沉浸阅读。Windows 支持方向键、PageUp/PageDown 与空格翻页。插图按正文位置显示，点击可打开缩放视图。

阅读时默认隐藏上下工具栏和章节提示，点击正文中间显示，再点击隐藏；长按仍可选择文字。平板实际滚动区域覆盖整个视口，左右留白也可上下拖动，正文保持居中限宽。

0.1.1 修正独立版错误继承私有镜像默认配置的问题：搜索与评论使用 Kazumi 原有的 Bangumi 官方直连路径，旧配置只迁移一次，可在网络设置自行选择。HTTP 失败显示实际错误，与真正没有搜索结果分开。弹幕接口保持弹弹play官方路径，独立应用凭据申请暂缓，当前未配置时明确提示不可用。

阅读位置自动写入本地；书签用于另外标记想再次阅读的位置。更换字号、窗口大小或阅读方式时按正文位置恢复，不把页码当作跨设备位置。外观设置按设备保存。

跨源续读先匹配章节，再核验正文锚点及插图位置。无法唯一对应时，可选择章节；人工确认的对应关系会保存并同步。若正文不匹配，可重新选章、保留原进度，或明确选择从本章开头开始。不同译本、缺章、拆合章和重新编码的插图不能保证全自动对应。

## WebDAV 自动同步

在“设置 → 多设备同步”中配置自己的 WebDAV，启用总开关和小说同步。小说书架也可以启用小说开关、查看失败原因或手动触发同步。

阅读时持续自动保存本地，启用后在修改后约 15 秒内安排云同步，并在应用回到前台、进入后台及周期检查时同步。规则文件、正文和图片缓存留在本机，不随 WebDAV 传输；作品关联、版本与书源绑定、阅读位置、人工章节映射和书签放在云端小说专用目录。并发修改会提示选择，不按设备时间或“最远进度”静默覆盖。

新设备首次搜索或阅读会自动获取默认规则。非默认的自定义书源仍需由用户添加；默认安装只自动替换索引明确声明的旧版原文摘要，保留用户改写规则。用户主动删除规则后，不会在每次打开应用时重新强装。

Nextcloud 可把 WebDAV 基址指向 `/remote.php/dav/files/你的登录ID/指定目录/`。目录名含中文时原样填写中文和末尾 `/`，不要预先转成百分号编码；当前官方 `webdav_client` 的 MOVE 会再次编码地址。密码使用 Nextcloud“个人设置 → 安全 → 设备和会话”生成的应用密码。

同一个 WebDAV 地址可以在官方 Kazumi 与本应用使用。观看记录、收藏模型和同步流程沿用官方 2.3.9 基线；小说使用 `/kazumiSync/novels/v1/`，官方按既有文件名读取与清理，不会同步或删除小说目录。小说进度只在支持小说的客户端之间同步，不能在官方界面阅读。

## 同步 Kazumi 上游更新

在产品分支提交当前修改后，从仓库目录运行：

```powershell
powershell -File dev/sync-upstream.ps1 -CheckOnly
powershell -File dev/sync-upstream.ps1
```

脚本将 `upstream/main` 合并到 `feature/novel-reader`，保留双方历史。遇到冲突时停在 Git 的合并状态，解决后提交；需要撤销本次合并时使用 `git merge --abort`。随后检查名称、应用标识、版本和更新地址，运行测试，推送产品分支触发 Android/Windows 构建。不要把产品改动合回用作上游镜像的 `main`。

应用检查更新只访问 `ZGCC3890/Kazumi-s-book` 的 Releases。先推送产品分支，由 `book-ci.yml` 完整测试并构建固定签名 Android APK 与 Windows ZIP；全部成功后给同一提交推送 `0.*` 版本标签，`book-release.yml` 校验提交与版本一致，直接发布该成功构建的产物及 SHA256SUMS，不重复打包。标签必须为纯数字版本（例如 `0.1.0`），与 `pubspec.yaml` 版本名一致，供现有更新比较器使用。上游发布工作流仅允许在 `Predidit/Kazumi` 运行，避免 fork 使用官方打包与签名流程。

实施状态与证据见[方案](Kazumi-轻小说实施方案.md)和[Astra 审查记录](Kazumi-架构审查记录.md)。
