# Kazumi's book 0.1.1

- 修复独立版镜像签名缺失导致番剧搜索、评论无法加载；恢复 Kazumi 已有的 Bangumi 官方直连路径，升级自动迁移错误默认配置。
- 平板两侧留白可滚动阅读，工具栏默认隐藏，点击正文中间显示／隐藏。
- 阅读超过一章退出询问加入书架；确认时关联番剧加入追番并标记“在看”。
- 小说搜索改为紧凑多源弹窗，自动去掉番剧的第二季／第二部分／Part 2 等后缀。
- 新增轻之文库（中文原创）、LightNovel（中文译文）规则，自动获取；目录分页和原位插图已按真实站点验证。受限章节会明确报错。

弹幕仍使用上游弹弹play官方接口；本应用的 AppId/AppSecret 需要独立申请并配置。凭据未就绪前，本版本不能恢复在线弹幕，不把缺凭据显示为零弹幕。

Android arm64 与 Windows 测试包待 CI 后发布；已有 0.1.0 保持同一签名，可覆盖升级。设备交互仍待用户验收。

## 0.1.0

首个 Android / Windows 测试版本，保留 Kazumi 番剧功能，增加轻小说阅读。

- 番剧详情与追番卡片可直接进入小说；卡片播放按钮可直接选源观看。
- 默认小说规则首次自动获取，无需手动导入；书源规则仍在本仓库 `novel_rules/` 独立维护。
- 原生阅读器支持滚动、翻页、目录、字体、主题、键盘操作；插图按正文顺序显示并可点击缩放。
- 自动记录阅读位置，支持书签、跨源章节映射与正文位置核验、WebDAV 多设备同步。
- 独立应用身份、固定 Android 签名和本仓库更新检查，可与官方版共存。

Android：安装 arm64 APK。Windows：完整解压 ZIP，运行 `kazumis_book.exe`。曾安装旧开发签名 APK 的设备需要先卸载旧开发包；本次固定签名会用于后续版本。

文库8公开书籍正文与插图支持匿名访问，站内搜索需要每台设备首次登录本人账号；会话仅存本机，密码不保存、不上传。会话失效或站点要求验证时会显示实际错误。小説家になろう为日文原作书源，访问仍受所在网络及站点限制，本环境尚未完成其真实正文联网验收。

同一 WebDAV 地址可以用于官方 Kazumi 与本应用：原观看/收藏协议沿用官方基线，小说文件在 `kazumiSync/novels/v1/`，官方同步忽略该目录。不同译本或正文不一致时须确认章节位置，不能保证任意两种文本自动精确互转。

使用、书源与云盘配置：[使用与维护](https://github.com/ZGCC3890/Kazumi-s-book/blob/feature/novel-reader/docs/novel/使用与维护.md)。当前需要用户安装后验收真实阅读与交互效果。
